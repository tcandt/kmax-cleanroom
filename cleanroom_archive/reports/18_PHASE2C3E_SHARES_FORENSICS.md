  - `SHARE_CREATE_CONTRACT.json`: Requires `device_id`, optional `expire_seconds` and `password`. Uniqueness enforced: returns HTTP 409 conflict when active share already exists on the device.
  - `SHARE_LIST_CONTRACT.json`: Admin lists active shares; supports query filtering `?device_id=...`; non-admin rejected with 403.

- [x] **Token & Card Generation**:

  - Password Hash: Plain `SHA256(password)` (64-char lowercase hex string, no salt).
- [x] **Expiry & Reaper Goroutine**: Permanent shares represent expiry as Go zero time (`0001-01-01T00:00:00Z`). Expiring shares store absolute timestamp. Background worker at VA `0x73a120` (`main.dYBSRoVh.func1`) runs periodic reaping and disk flush.

## 4. Operational Contracts Summary

### 4.1 `/api/share/create` (POST)
- Accepts: `{"device_id": "...", "expire_seconds": int, "password": "...", "access_mode": "...", "allow_clipboard": bool, "allow_file_tx": bool, "forbid_audio": bool, "description": "..."}`.
- If `device_id` missing: returns `400 Bad Request` (`device_id is required\n`).
- If device already has active share: returns `409 Conflict` (`{"code":409,"msg":"该设备已存在活跃分享（卡密 ...），请先撤销或对其延时"}\n`).
- On success: returns `200 OK` with `{"code":0,"data":{"access_mode":"full","card_code":"CP-XXXX-XXXX","device_id":"...","expires_at":"...","share_url":"/share?token=st_...","token":"st_..."},"msg":"success"}\n`.

### 4.2 `/api/share/list` (GET)
- Returns: `200 OK` with `{"code":0,"data":[...]}`.
- If `?device_id=...` supplied: filters array to matching `device_id`.
- If empty: returns `{"code":0,"data":[]}\n`.

### 4.3 `/api/share/info` (GET)
- Query parameters: accepts `?token=st_...` or `?stoken=st_...`.
- If missing token: returns `400 Bad Request` (`Token required\n`).
- If token invalid/not found/expired: returns `404 Not Found` (`Share link expired or invalid\n`).
- If password-protected and password omitted/wrong: returns `200 OK` with `{"code":401,"data":{"require_password":true},"msg":"该分享需要访问密码"}\n`.
- On valid access: returns `200 OK` with full share metadata, `remaining_seconds`, `online` status, and `device_name`.

### 4.4 `/api/share/revoke` (POST)
- Accepts: `{"token": "st_..."}`.
- If token missing or not found: returns `404 Not Found` (`Share token not found\n`).
- On success: deletes entry from state, flushes to disk, and returns `200 OK` (`{"code":0,"msg":"Share revoked successfully"}\n`).

### 4.5 `/api/share/extend` (POST)
- Accepts: `{"token": "st_...", "extend_seconds": int}`.
- If `extend_seconds <= 0`: returns `400 Bad Request` (`token and positive extend_seconds are required\n`).
- If token is permanent (`0001-01-01T00:00:00Z`): returns `200 OK` with `{"code":400,"msg":"永久有效的分享无需延时"}\n`.
- On expiring share: adds seconds to `expires_at` and returns `200 OK` with `{"code":0,"data":{"expires_at":"..."},"msg":"success"}\n`.

### 4.6 `/api/share/update` (POST)
- Accepts: `{"token": "st_...", "allow_clipboard": bool, "allow_file_tx": bool, "forbid_audio": bool, ...}`.
- If `token` missing: returns `400 Bad Request` (`token is required\n`).
- On success: updates fields and returns `200 OK` with `{"code":0,"data":{...},"msg":"success"}\n`.

### 4.7 `/api/share/redeem_card` (POST)
- Accepts: `{"card_code": "CP-XXXX-XXXX"}`.
- If `card_code` missing: returns `400 Bad Request` (`card_code is required\n`).
- If `card_code` not found: returns `200 OK` with `{"code":404,"msg":"卡密不存在或已失效"}\n`.
- On success: returns `200 OK` with `{"code":0,"data":{...},"msg":"success"}\n`.
